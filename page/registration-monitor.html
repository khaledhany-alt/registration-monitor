Registration Monitor

Each check goes through the same four steps a visitor does: open the signup page, fill the form with an Egyptian phone number (a Saudi one can trigger the SMS code step), submit it, and land signed in on the new account. Test accounts are kept; their login URLs start with regmon and their business name is “Registration Monitor”. The checks run every hour on Claude’s cloud, so they keep going when nobody’s computer is on.
